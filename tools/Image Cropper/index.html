How to crop an image

  1. Select a JPG, PNG or WebP image.
  2. Choose a crop ratio or select Free crop.
  3. Drag the crop selection to position it and resize it using its handles.
  4. Click Crop Image, preview the result and download it.

Frequently asked questions

What is an aspect ratio?

It describes the relationship between the width and height of the crop area. Square is useful for profile pictures, while 16:9 is commonly used for video thumbnails.

Will cropping improve image quality?

Cropping removes unwanted parts of an image but does not add detail that was not in the original.

Is my image uploaded to a server?

No. The image is designed to be processed locally in your browser.
